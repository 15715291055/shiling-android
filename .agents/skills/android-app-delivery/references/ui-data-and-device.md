# 原生界面、数据与系统能力

只读取当前功能涉及的段落；这些是可选能力，不是所有应用必须实现的功能清单。

## 阅读、输入与滚动

长文页面应明确由哪个容器负责垂直滚动，避免固定高度正文框、嵌套同方向滚动和父级手势抢走普通阅读。测试内容应超过多屏，并包含多图、大字号和输入法。

阅读与编辑分离时，阅读默认展示完整文本；编辑使用随内容增长的无边框输入组件和独立草稿。保存才提交数据库，取消恢复原内容，有修改时返回需处理草稿。

若要求双击原位编辑：使用文本布局信息将双击坐标映射到字符偏移；切换为相同文字样式的 `BasicTextField`，恢复焦点和键盘，维持页面滚动位置。保留显式编辑入口供无障碍使用和修改元数据。不要双击后跳到一套表单，也不要在进入编辑时继续允许跨记录/日期的拖动切换。

## 到边界后才切换日期或记录

普通滚动交给列表/滚动容器，只有到边界后的剩余拖动参与翻页。使用 nested scroll 等适合现有实现的机制协调，不用覆盖整个屏幕的拖动监听截走全部输入。

可采用以下状态：正常滚动 → 边界拖动 → 达到阈值 → 松手切换，或反向退回阈值内取消。阻尼应连续、非线性并保留跟手感。相邻内容提前准备，动画从当前位移衔接，避免先弹回原位再突然换内容。

需要观察的行为：中段长文不翻页；未达阈值回弹；越过再退回可取消；只有松手提交；编辑中不跨页；日期和日历选中状态同步。原生 Overscroll 不是整个功能的替代品。

## 图片、预览和系统分享

- 系统选择器返回的 URI 不能假设永远有效。依需求获取持久 URI 权限，或复制到应用私有文件并存储引用。
- 保留原图还是压缩必须明确。若有缩略图，独立保存，不能悄悄覆盖原文件；测试 EXIF 方向、大图和多图内存占用。
- 缩略图需要真正可触达的全屏入口。子图片点击不能误触发父卡片编辑；缩放后的平移与左右翻图要协调。
- 列表与长图预览给出确定尺寸或比例，按显示尺寸解码，避免一次加载所有高清分页。
- 使用受限 FileProvider URI 和临时读取授权调用系统分享，不暴露整个私有目录。相册保存使用适合目标 Android 版本的 MediaStore 流程。

图文分享模板应动态排任意长度的真实内容：分页保留全部正文和选中图片，照片正确裁切与旋转，最后一页按内容收紧。用 0 图、1 图、多图与跨页长文验证。设计稿上的漂亮短句不能代替这些数据边界。

## 主题、背景与毛玻璃

用语义颜色区分主标题、正文、辅助、日期与强调色；一个强调色派生深浅层级，不能全部替换成同一个 HEX。设置应持久化，并在重建后读回。颜色对比保护不应使不同页面出现无解释的跳色。

壁纸按比例裁切或以渐变衔接，避免拉伸。需要全屏壁纸时，将背景画到系统栏后方，交互内容仍避让安全区；同时验证深浅背景的系统图标可读性。

毛玻璃应模糊背景来源而非文字本身。卡片和底部导航可独立控制材质透明度；避免给整棵组件设置 alpha。可预先处理固定壁纸并按屏幕区域采样以降低成本，但要如实描述能力，不能称其为捕获所有实时内容的专有折射效果。

若拖动时莫名变深，检查：重复透明层合成、长卡片整体渐变、ripple/按压缩放、系统 Overscroll 和预览层未裁切。用合成长文对比静止、按住、拖动的同一屏幕区域；不能为了消除变色直接删掉用户需要的玻璃效果。

## 权限、定位与失败状态

按用户操作请求权限，处理拒绝与永久拒绝；用户只同意主动定位时不要改成持续追踪。检查近似定位、无可用结果、网络断开与取消。地图瓦片等第三方网络请求要与“业务数据只在本机”分开说明。

涉及系统安装验证、锁屏密码或指纹时由机主操作。停在当前安全页面，不绕过验证、不要求用户把密码发给代理。

## 备份、恢复与兼容

导出完成后再读取文件：非零大小、ZIP CRC、结构和资源引用均需有效。点击保存或文件刚创建，不代表异步写入已经结束。

导入先解包到私有临时区，检查路径穿越、大小限制、格式版本、图片引用和 ID 冲突，按产品定义的规则合并并事务提交。失败时保留原数据；不要在验证前清库。设置、心情/标签、历史快照等关联内容按实际 schema 覆盖，不能只备份正文。

## 离线每日内容（仅在需求涉及时）

区分已核实引文、翻译与原创示例。保存作者及来源，不编造作家署名。用户要求数年不重复时，准备足够不同内容并验证调度；已经使用的稳定 ID/索引不能因后续重排语料而重用。明确语料耗尽后的行为，不能用取模循环却宣称永不重复。
