# 分享卡片参考与拾零实现

查阅日期：2026-11-23。仅研究公开的界面、排版与分享流程，不把其他应用截图或文字素材嵌入拾零。

- [flomo 实际分享图示例](https://help.flomoapp.com/community/tips/reading.html)：观察白色卡片、段落留白、弱化页脚信息，以及生成后直接预览、保存的流程。已在本目录保存官方示例供内部视觉核对。
- [Day One 导出说明](https://dayoneapp.com/guides/settings/exporting-entries/)：官方描述 Share Card 组合日期、文字、照片，适用于有图和无图记录。参考的是图文完整性与独立预览流程，并非声称复制其某款视觉模板。
- [Bear 图片导出说明](https://bear.app/faq/export-your-notes/)：JPG 用于分享，保留阅读型排版的思路。
- [EMMO 开发者介绍](https://apps.apple.com/cn/app/id1508326506)：参考心情表情、文字、照片组合的表达方式，不使用其自绘表情或贴纸。

拾零共实现 8 套原创代码绘制的分享样式：纸页手账、极简排版、胶片拼贴、文学日签、生活杂志、便笺卡片、心情小报、旅行明信片。差异包括刊头、日期尺度、正文字体、卡纸边界、照片顺序和拼贴方式。

所有模板沿用全文分页引擎，单张宽 1080、最高 2800 像素，末页按内容收紧。模板不借用外部语录、不编造位置，也不上传任何日记。

预览修复：显式计算图片比例、单页解码降低内存占用、生成后滚动到预览入口，缩略图与按钮都可打开全屏查看。全屏支持双击/双指缩放与左右翻页。
